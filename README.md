## 🇬🇧 About the Project

This repository documents my personal IT homelab, created to develop practical skills required for a **Junior IT Support / Junior System Administrator** position.

The main goal is to build and manage a small virtual IT infrastructure, troubleshoot technical problems, and document the entire learning process.

## 🇵🇱 O projekcie

To repozytorium dokumentuje moje prywatne laboratorium IT, stworzone w celu zdobywania praktycznych umiejętności potrzebnych na stanowisku **Młodszy Informatyk / Junior IT Support**.

Głównym celem jest zbudowanie i zarządzanie małą infrastrukturą IT, rozwiązywanie problemów technicznych oraz dokumentowanie całego procesu nauki.

## 🎯 Project Goals | Cele projektu

### 🇬🇧 English

- Learn Linux server administration.
- Configure Windows Server and Active Directory.
- Understand DNS and DHCP services.
- Practice network configuration and troubleshooting.
- Learn basic PowerShell automation.
- Simulate real-world IT Helpdesk scenarios.
- Create technical documentation.

### 🇵🇱 Polski

- Nauka administracji serwerem Linux.
- Konfiguracja Windows Server i Active Directory.
- Poznanie usług DNS i DHCP.
- Ćwiczenie konfiguracji sieci i diagnostyki problemów.
- Nauka podstaw automatyzacji za pomocą PowerShell.
- Symulowanie rzeczywistych zgłoszeń Helpdesk.
- Tworzenie dokumentacji technicznej.
