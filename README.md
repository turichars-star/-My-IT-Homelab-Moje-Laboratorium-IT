# -My-IT-Homelab-Moje-Laboratorium-IT
Practical IT Support &amp; System Administration Portfolio  Status: In Progress 
🇬🇧 About the Project

This repository documents my personal IT homelab, created to develop practical skills required for a Junior IT Support / Junior System Administrator position.

The main goal is to build and manage a small virtual IT infrastructure, troubleshoot technical problems and document the entire process.

🇵🇱 O projekcie

To repozytorium dokumentuje moje prywatne laboratorium IT, stworzone w celu zdobywania praktycznych umiejętności potrzebnych na stanowisku Młodszy Informatyk / Junior IT Support.

Głównym celem jest zbudowanie i zarządzanie małą infrastrukturą IT, rozwiązywanie problemów technicznych oraz dokumentowanie całego procesu.
